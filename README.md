#### 🧭 How I build agents

- **Ask before acting.** A human approves anything that changes the world, and the approval shows exactly what will run.
- **Untrusted text is data, not instructions.** Web pages, files and meetings can inform an agent, but they can never command it.
- **Arabic is a first-class language,** not a translation added later.
- **Run it in 5 minutes,** or it isn't a demo.
